# Nitshitey - Personal Portfolio Website 🌾📊
> **4th Year B.Sc. Agricultural Economics Student**  
> **University of Gondar (UoG), Ethiopia**

A modern, high-performance personal portfolio website built with clean HTML5, CSS3, and JavaScript, featuring an electric cyan neon glow aesthetic, interactive animations, and responsive design.

---

## 🌟 Key Features

- **Cyber-Neon Botanical Aesthetic**: Custom dark theme with electric cyan (`#0ef`) glow accents and modern typography.
- **Dynamic Typewriter Header**: Automatic text rotation highlighting roles at the University of Gondar (UoG).
- **Interactive About Section**:
  - **Download CV**: Working modal with curriculum breakdown and one-click CV document download.
  - **View Projects**: Smooth scroll with illuminated pulse animation across portfolio cards.
- **1st to 4th Year Curriculum Timeline**: Comprehensive academic progression at University of Gondar.
- **Interactive Testimonials**: Click-to-activate cards with real photos and glowing borders.
- **AgroEconomics Services & Portfolio**: Showcasing market analysis, farm linear programming, post-harvest valuation, and rural survey research.
- **Contact Form**: Interactive form with floating focus glow and toast notifications.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox).
3. (Optional) Run with VS Code's **Live Server** extension at `http://127.0.0.1:5500`.

---

## 🌐 Deploying to GitHub Pages (Free Live Website)

1. Push this folder to a new GitHub repository named `nitshitey-portfolio`.
2. Go to **Settings** ➔ **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your live link will be ready at:
   `https://<your-username>.github.io/nitshitey-portfolio`
